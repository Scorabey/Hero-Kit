# Hero-Kit

A React UI library written in TypeScript, implementing components based on the **HeroUI Figma Kit (Community)** design system. Styling is built with `styled-components`.

[![npm version](https://img.shields.io/npm/v/hero-kit.svg)](https://www.npmjs.com/package/hero-kit)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](./LICENSE)
[![TypeScript](https://img.shields.io/badge/TypeScript-Ready-blue.svg)](https://www.typescriptlang.org/)

---

## Features

- 🎨 Components based on the HeroUI Figma Kit (Community)
- ⚛️ Written in React + TypeScript
- 💅 Styled with `styled-components`
- 🌗 Theming support (light/dark)
- 📦 Lightweight, tree-shakeable out of the box
- ♿ Built with accessibility in mind

---

## Installation

```bash
npm install hero-kit styled-components
```

or

```bash
yarn add hero-kit styled-components
```

> `styled-components` is listed as a peer dependency and must be installed separately in your project.

---

## Development

```bash
git clone https://github.com/Scorabey/hero-kit.git
cd hero-kit
npm install
npm run dev
```

Build the library:

```bash
npm run build
```

Run tests:

```bash
npm run test
```
